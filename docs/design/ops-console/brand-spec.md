# KnowHub exploration system

The prototype holds one shared content model and applies three deliberately contrasting interface systems.

## Option A — Ops Console

```css
--bg: oklch(98% 0.005 250);
--surface: oklch(100% 0 0);
--fg: oklch(22% 0.02 240);
--muted: oklch(50% 0.018 240);
--border: oklch(90% 0.008 240);
--accent: oklch(58% 0.16 145);
```

- Display: IBM Plex Sans Condensed, Aptos Narrow, system sans-serif
- Body: IBM Plex Sans, Segoe UI, system sans-serif
- Mono: IBM Plex Mono, JetBrains Mono, ui-monospace
- Square panels, tabular numerics, compact spacing, status-led scanning.

## Option B — Knowledge Studio

```css
--bg: oklch(98% 0.004 95);
--surface: oklch(100% 0.002 95);
--fg: oklch(20% 0.018 70);
--muted: oklch(48% 0.012 70);
--border: oklch(90% 0.006 95);
--accent: oklch(52% 0.10 28);
```

- Display: Iowan Old Style, Charter, Georgia, serif
- Body: Source Sans 3, Segoe UI, system sans-serif
- Mono: IBM Plex Mono, ui-monospace
- Reading-first rhythm, open whitespace, rules instead of card chrome.

## Option C — Delivery Ledger

```css
--bg: oklch(99% 0.002 240);
--surface: oklch(100% 0 0);
--fg: oklch(18% 0.012 250);
--muted: oklch(54% 0.012 250);
--border: oklch(92% 0.005 250);
--accent: oklch(58% 0.18 255);
```

- Display: Helvetica Neue, Nimbus Sans, system sans-serif
- Body: IBM Plex Sans, Segoe UI, system sans-serif
- Mono: IBM Plex Mono, ui-monospace
- Swiss grid, strong rules, numbered sections, disciplined blue accent.
